# TaskFlow

### Task Management & Team Collaboration Web Application

TaskFlow is a web application for managing projects, organizing tasks, tracking progress, and coordinating team workflows.

I built this project as part of my frontend development portfolio to practice building a complete application with interactive features, reusable components, application state management, and responsive design.

## Features

### Authentication

* Sign up and sign in
* User session management
* Profile and account settings
* Sign out

### Project Management

* Create, edit, and delete projects
* View project details and progress
* Archive and restore projects
* Organize tasks within projects
* Search and filter projects

### Task Management

* Create, edit, and delete tasks
* Assign tasks to team members
* Set task status and priority
* Add due dates
* Add labels and descriptions
* Search and filter tasks

### Kanban Board

* Organize tasks by workflow status
* Move tasks between statuses
* View task counts by status
* Open and manage task details directly from the board

### Dashboard

* Overview of projects and tasks
* Project and task statistics
* Progress tracking
* Upcoming deadlines
* Recent activity

### Team Management

* Manage team members
* Assign tasks
* View team workload
* User profiles

### User Experience

* Responsive design for desktop, tablet, and mobile
* Global search and filtering
* Notifications
* Confirmation dialogs and feedback messages
* Consistent navigation and reusable UI components

## Project Structure

TaskFlow is built using reusable React components and application pages. The project separates UI components, application logic, and data handling to keep the code organized and easier to maintain.

The current version uses client-side state and persistence. The application structure can be extended with a backend API and database in the future.

## Getting Started

### Prerequisites

You will need Node.js and npm installed on your computer.

### Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd taskflow
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open `http://localhost:3000` in your browser.

## Current Scope

TaskFlow is currently a frontend-focused portfolio project.

The main focus of the project is building a complete and interactive user experience, including project and task management, authentication, navigation, state management, responsive design, and client-side data persistence.

A production version could be extended with a backend, database, secure server-side authentication, and real-time collaboration.
